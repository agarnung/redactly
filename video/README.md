# Demo video

The video must be **public on YouTube**, **under 3 minutes**, and in **English**
or with **English subtitles**.

- Script: [`../VIDEO-SCRIPT.md`](../VIDEO-SCRIPT.md)
- Subtitles: [`subtitles.srt`](subtitles.srt)
- Recommended upload: 1920×1080, 30 fps, public, English narration.

Do not show `.env`, API keys, project IDs, debug tokens, emails or personal data.
Record the app in Chrome; use the mock flow if the real Firebase config is not
ready.
